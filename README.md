# Astaga-naga — Godot Action RPG

Offline 2D top-down pixel-art Action RPG for Android, based on the gameplay feel of `Pixel_RPG_World_Upgrade_Stable.html`.

## Planned foundation
- Manual real-time sword combat and active skills with cooldowns
- Touch-friendly controls and HUD
- 10 unlockable maps, village, NPCs, shops, quests, enemies, elites, and bosses
- EXP, levels, gold, inventory, equipment, potions, attributes, and local save data
- Android export workflow via GitHub Actions

The first implementation is being added as a self-contained Godot project. Visuals are generated with Godot drawing primitives for now, so no external asset downloads are required.
