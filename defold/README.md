# Astaga-naga — Defold prototype

This folder is the new Defold implementation. The previous Godot files remain in the repository as a fallback/reference while the Defold Android build is verified.

## First milestone

- Defold GUI-based playable prototype with a tile-like village field.
- Tap/drag to move, tap Attack, Skill, and Potion controls.
- Monster chase, HP, EXP, levels, gold, elite enemies, and respawn.
- GitHub Actions Android APK build.

## Build

Open the repository's Actions tab and run **Build Defold Android APK**. On success, download the astaga-naga-defold-android-apk artifact.

This is a prototype, not the completed RPG: ten distinct authored maps, NPC/shop/quest content, equipment inventory, save/load, unique boss encounters, and production pixel-art assets still need implementation and device testing.
